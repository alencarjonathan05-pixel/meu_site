Quem sou eu?

Meu nome é Jonathan Alencar. Sou o autor e desenvolvedor do projeto CineBook.

Este site foi desenvolvido como um projeto acadêmico para apresentar informações sobre filmes e praticar os conhecimentos de desenvolvimento web.

Sobre o CineBook

O CineBook é um site criado para apresentar filmes, suas informações, descrições e detalhes de forma simples e organizada.

Objetivo do projeto

O objetivo deste projeto é colocar em prática os conhecimentos aprendidos em HTML e, posteriormente, utilizar CSS e JavaScript para melhorar o site.
